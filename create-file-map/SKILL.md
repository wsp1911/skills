Explore the implementation of a certain function/module and organize the relevant files into a file index.

If not specified, save the output file to the root directory of the target repo.

## Format

Output a markdown table with three columns: file path, summary, and line number range.
- the file path is relative to the target repo
- the summary should be consise
- line number range is optional
